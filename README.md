# Альтрон

Ассистент старосты в Telegram-группе. Живёт только в чате группы: читает переписку, отвечает, спорит, стебётся (чёрный юмор, мат), пишет отчёты в Word, делает опросы, напоминания, закрепы, кидает стикеры, смотрит фото по просьбе и помнит людей.

## Возможности
- **Обращение:** «альтрон …», @упоминание или реплай на его сообщение. Иногда влезает в разговор сам (шанс настраивается).
- **Ассистент старосты:** отчёты и объявления (`.docx`), напоминания, опросы и викторины, закрепы, мут, заметки о группе, факты о людях.
- **Фото:** смотрит только по просьбе — фото с подписью «альтрон …», реплай на фото или «альтрон глянь фото».
- **Правила:** «альтрон новое правило: если много пишут — пиши: пишите суть чуть тише». При флуде выполняет.
- **Режим копирования:** пишет манерой старосты (или любого участника).
- **Меню старосты:** `/menu` в личке бота — баннер и кнопки: чат, правила, заметки, напоминания, люди, характер, статистика, синк.
- **Память в GitHub:** история чатов, люди и заметки раз в 10 минут уходят в приватный репозиторий `ultron-memory`. На новом сервере всё поднимается оттуда само.

## Запуск на компьютере
1. `uv venv --python 3.13 .venv` и `uv pip install --python .venv/Scripts/python.exe -r requirements.txt`
2. Скопировать `.env.example` в `.env`, вписать `BOT_TOKEN`.
3. `Запуск.bat`

## Хостинг — прямо в GitHub Actions (бесплатно)
Workflow `.github/workflows/bot.yml` держит бота онлайн:
- один запуск работает ~5.5 часа, потом сам сохраняет память в `ultron-memory` и запускает следующий (перерыв ~1 минута, сообщения не теряются);
- `git push` в `main` — бот за пару минут уступает место запуску с новым кодом;
- упал — cron раз в час поднимет его снова;
- всё состояние (история, люди, правила, заметки, напоминания, настройки, стикеры) живёт в приватном репозитории `ultron-memory` и поднимается при каждом старте.

Секреты репозитория: `BOT_TOKEN`, `LLM_API_KEY`, `OWNER_IDS`, `MEMORY_DEPLOY_KEY` (deploy-ключ с записью в `ultron-memory`). Переменная `ALLOWED_CHATS` — по желанию.
Перед запуском в Actions бота на компьютере надо выключить: одновременно может работать только один.

## Тесты
`.venv\Scripts\python -X utf8 tests\test_bot.py` — 18 сценариев на фейковом Telegram: ответы, опросы, права админа, правила и флуд, фото по просьбе, Word-отчёт, напоминания, меню, память GitHub.

## BotFather
`/setprivacy` → Disable (иначе бот не видит переписку), потом добавить бота в группу заново и дать админку.
